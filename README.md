## Quick Start

<p align="center">
  <img src="https://user-images.githubusercontent.com/74038190/238353480-219bcc70-f5dc-466b-9a60-29653d8e8433.gif" width="420" alt="Developer at a desk" />

1. **Locate a Prompt**: Use the [Master Index](INDEX.md) to search for specific topics, technologies, or tags.
2. **Copy the Prompt**: Copy the contents inside the `## 🎯 Prompt` code block in the markdown file. (Note: Sub-pages preserve the emoji targets for compatibility).
3. **Fill the Placeholders**: Replace any `[BRACKETED PLACEHOLDERS]` with details specific to your codebase or requirements.
4. **Feed to Claude**: Paste the prompt into Claude (Sonnet, Opus, or Fable) and watch it generate production-ready code.

### Pro Tips for Claude
- **Use Extended Thinking**: When working with architecture design (`10-*`), debugging (`09-*`), or security (`14-*`), toggle **Extended Thinking** on Sonnet 4 or Fable 5. This forces the model to construct chain-of-thought analysis before outputting code.
- **Provide Context**: Copy relevant parts of your current files or directory structure and append it to the prompt.

## Use as a Claude Skill

The whole library is also packaged as one Claude skill, [`skill/claude-cheatcodes`](skill/claude-cheatcodes). Describe a task, for example "optimize my React app" or "design a Postgres schema". Claude finds the best-matching prompt, fills the placeholders from your context, and either hands you the prompt or runs it.

**Install in the Claude apps:** download [`skill/claude-cheatcodes.zip`](skill/claude-cheatcodes.zip), go to **Settings → Capabilities → Skills**, choose **Upload skill** and select the zip. Code execution must be enabled.

**Install in Claude Code:** copy the folder into your skills directory:

```bash
cp -r skill/claude-cheatcodes ~/.claude/skills/        # all projects
# or: cp -r skill/claude-cheatcodes .claude/skills/   # this project only
```

**Search the library from the terminal:** `python3 skill/claude-cheatcodes/scripts/search.py "jwt auth api"`

**Rebuild after editing prompts:** `python3 scripts/build_skill.py`. This regenerates `references/` and the zip, collapses generated variants into parameterised templates, and prints a parse and coverage report.
