## 🎯 Prompt

```
Help me solve this algorithms problem.

Problem: [PASTE THE PROBLEM STATEMENT]
My attempt: [PASTE YOUR CODE IF YOU HAVE ONE]

1. **Understand the problem**: what are the inputs, outputs, constraints?
2. **Examples**: walk through the provided examples
3. **Brute force**: simplest solution (even if slow)
4. **Optimize**: what's the bottleneck? How to improve?
5. **Pattern recognition**: which algorithm pattern applies?
   - Two pointers
   - Sliding window
   - Binary search
   - BFS/DFS
   - Dynamic programming
   - Greedy
   - Divide and conquer
6. **Optimal solution**: with time + space complexity analysis
7. **Code**: clean implementation with comments
8. **Edge cases**: empty input, single element, duplicates, negative numbers
9. **Test**: verify against all examples
10. **Alternative**: other valid approaches

Output: complete walkthrough from brute force to optimal.
```
