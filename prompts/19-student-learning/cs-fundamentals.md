## 🎯 Prompt

```
Teach me computer science fundamentals.

My background: [DESCRIBE YOUR CURRENT LEVEL]
Goal: [DESCRIBE WHAT YOU WANT TO ACCOMPLISH]

Topics to cover:

**Data Structures** (with implementations):
1. Arrays: static vs dynamic, time complexity
2. Linked lists: singly, doubly, circular
3. Stacks and queues: LIFO/FIFO use cases
4. Hash tables: collision resolution, load factor
5. Trees: BST, AVL, B-tree, heap
6. Graphs: representations, directed vs undirected

**Algorithms**:
7. Sorting: bubble, merge, quick, heap — when to use each
8. Searching: linear, binary, BFS, DFS
9. Dynamic programming: memoization, tabulation
10. Greedy algorithms: when they work

**Complexity**:
11. Big O notation: O(1), O(log n), O(n), O(n log n), O(n²)
12. Space vs time trade-offs

For each topic: explanation + code example + practice problem.
```
