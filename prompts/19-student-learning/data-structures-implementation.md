## 🎯 Prompt

```
Implement data structures from scratch to deepen understanding.

Data structure to implement: [LINKED LIST / BINARY TREE / HASH MAP / GRAPH / PRIORITY QUEUE]
Language: [PYTHON / JAVASCRIPT / TYPESCRIPT]

For the chosen data structure, implement:

1. **Node class**: data + pointer structure
2. **Core operations**: insert, delete, search
3. **Edge cases**: empty structure, single element, duplicates
4. **Time complexity**: O notation for each operation
5. **Space complexity**: memory usage

Also implement and explain:
6. Traversals (if applicable): in-order, pre-order, post-order, BFS, DFS
7. Balancing (for trees): rotations, AVL or Red-Black
8. Resizing (for hash maps): when and how to resize

Testing:
9. Test every operation
10. Test all edge cases

Comparison:
11. How does the built-in language equivalent compare?
12. When would you use the built-in vs custom implementation?
```
