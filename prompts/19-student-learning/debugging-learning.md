## 🎯 Prompt

```
Teach me how to debug code effectively.

Language: [DESCRIBE YOUR LANGUAGE]
Experience level: [BEGINNER / INTERMEDIATE]

Debugging mindset:
1. **Reproduce first**: confirm you can trigger the bug consistently
2. **Understand before fixing**: don't randomly change code
3. **Scientific method**: form hypothesis → test → iterate

Debugging tools:
4. `console.log()` / `print()`: quick and effective
5. Debugger: set breakpoints, step through code
6. Browser DevTools: network, console, breakpoints
7. IDE debugger: VS Code Debug panel
8. Logging: structured logs with context

Debugging strategies:
9. **Binary search**: comment out half, narrow down
10. **Rubber duck**: explain the bug out loud
11. **Simplify**: create minimal reproduction case
12. **Fresh eyes**: take a break, come back
13. **Ask for help**: with a clear description

Practice:
14. Common bug patterns to recognize
15. How to write a good bug report

Apply to: [DESCRIBE YOUR CURRENT BUG IF ANY].
```
