## 🎯 Prompt

```
Teach me Git from the beginning.

Goal: [PERSONAL PROJECTS / TEAM COLLABORATION / OPEN SOURCE CONTRIBUTION]

Git fundamentals:

**Week 1 — Basic Commands**:
1. What is version control? Why Git?
2. `git init` and `git clone`
3. `git add` and `git commit`
4. `git log`: see history
5. `git status` and `git diff`
6. `.gitignore`: what to ignore

**Week 2 — Branching**:
7. `git branch`: create, list, delete
8. `git checkout` / `git switch`
9. `git merge`: combine branches
10. Resolving merge conflicts

**Week 3 — Remote**:
11. GitHub: repos, profile, README
12. `git remote add origin`
13. `git push` and `git pull`
14. Fork + Pull Request workflow

**Week 4 — Collaboration**:
15. Code review process
16. Branch protection rules
17. `git rebase` basics

Mistakes to avoid + how to undo mistakes.
```
