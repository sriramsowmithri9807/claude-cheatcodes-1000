## 🎯 Prompt

```
Help me master modern JavaScript.

My level: [BASICS DONE / INTERMEDIATE / DEEP DIVE]

Modern JavaScript features to master:

**ES6 fundamentals**:
1. `const` and `let` vs `var` (scope, hoisting)
2. Arrow functions: syntax + this binding differences
3. Template literals: string interpolation + multiline
4. Destructuring: arrays and objects
5. Default parameters and rest/spread
6. Modules: `import`/`export`

**Async JavaScript**:
7. Callbacks and callback hell
8. Promises: `.then()`, `.catch()`, `Promise.all()`
9. `async/await`: clean async syntax
10. Error handling in async code

**Advanced concepts**:
11. Closures: what they are and common use cases
12. Prototype chain: how inheritance works in JS
13. Event loop: why JS can be 'single-threaded'
14. `this` keyword: the 6 rules
15. WeakMap and WeakRef: memory-efficient references

For each: concept explanation + common mistakes + practical examples.
```
