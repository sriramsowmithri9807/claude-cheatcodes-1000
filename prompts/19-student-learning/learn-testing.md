## 🎯 Prompt

```
Teach me software testing from basics to TDD.

Language: [JavaScript / Python / other]
Current knowledge: [NEVER WRITTEN TESTS / SOME UNIT TESTS / REFRESH]

**Why testing matters**:
1. Catch bugs before users do
2. Refactor safely
3. Documentation that stays current
4. Confidence to deploy

**Types of tests**:
5. Unit tests: test one function in isolation
6. Integration tests: test multiple units together
7. E2E tests: test the whole application

**Unit testing fundamentals** (Jest/Vitest):
8. Describe and it blocks
9. Arrange-Act-Assert pattern
10. Matchers: toBe, toEqual, toContain, toThrow
11. Mocking: mock external dependencies
12. Coverage: what to aim for

**TDD Workflow**:
13. Write failing test
14. Write minimum code to pass
15. Refactor
16. Repeat

**Practice**: build a calculator module using TDD, showing each step.
```
