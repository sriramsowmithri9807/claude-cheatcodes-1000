## 🎯 Prompt

```
Teach me programming from scratch.

Language choice: [Python is recommended for beginners]
Time commitment: [HOURS PER WEEK]
Goal: [DESCRIBE WHAT YOU WANT TO BUILD]

Week-by-week curriculum:

**Week 1 — Foundations**:
1. What is a computer program?
2. Variables: store and use values
3. Data types: strings, numbers, booleans
4. Print output, read input
5. Basic arithmetic

**Week 2 — Control Flow**:
6. If/else: make decisions
7. Loops: repeat actions (for, while)
8. Functions: reusable code blocks

**Week 3 — Data Structures**:
9. Lists: ordered collections
10. Dictionaries: key-value pairs

**Week 4 — First Project**:
11. Build a simple project: calculator, quiz, todo list

For each concept: explain with analogy + working code example + simple exercise.
Common beginner mistakes to avoid.
```
