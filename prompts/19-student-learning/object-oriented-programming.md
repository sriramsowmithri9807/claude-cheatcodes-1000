## 🎯 Prompt

```
Teach me Object-Oriented Programming.

Language: [Python / Java / TypeScript]
Current level: [UNDERSTAND FUNCTIONS / SOME OOP / REFRESH]

OOP concepts with real-world analogies:

1. **Classes and objects**: blueprint vs instances
2. **Encapsulation**: hiding internal details
   - Private vs public attributes and methods
3. **Inheritance**: child class extends parent class
   - Is-a relationship
   - Method overriding
   - Super() to call parent
4. **Polymorphism**: same interface, different behavior
   - Method overloading vs overriding
5. **Abstraction**: abstract classes and interfaces
6. **Composition**: has-a relationship (vs inheritance)
7. **SOLID principles**:
   - Single Responsibility
   - Open/Closed
   - Liskov Substitution
   - Interface Segregation
   - Dependency Inversion

For each concept: analogy + code example + bad vs good example.
```
