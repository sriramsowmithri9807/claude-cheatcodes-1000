## 🎯 Prompt

```
Help me make my first open source contribution.

My skills: [DESCRIBE YOUR PROGRAMMING SKILLS]
Time available: [HOURS PER WEEK]

Step-by-step guide to first contribution:

**Finding a project**:
1. `good first issue` label on GitHub
2. `hacktoberfest` tag in October
3. Projects you actually use
4. github.com/explore
5. Size: start with smaller projects

**Contributing process**:
6. Read CONTRIBUTING.md first
7. Comment on issue to claim it
8. Fork the repository
9. Clone your fork
10. Create a feature branch
11. Make the change
12. Add/update tests
13. Submit a Pull Request
14. Respond to review feedback

**Your first PR**:
15. Look for: typos, documentation, small bugs
16. Respect the existing code style
17. Write a good PR description

**After merging**:
18. Add to your portfolio
19. Continue contributing (you're now a contributor!)
```
