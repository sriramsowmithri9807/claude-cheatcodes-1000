## 🎯 Prompt

```
Teach me Python progressively.

My background: [COMPLETE BEGINNER / KNOW ANOTHER LANGUAGE / REFRESHING]
Goal: [WEB SCRAPING / DATA SCIENCE / AUTOMATION / GENERAL PROGRAMMING]

Learning path:

**Beginner** (Weeks 1-3):
1. Variables, data types, operators
2. Control flow: if/else, for, while
3. Functions: define, call, arguments, return
4. Lists and tuples
5. Dictionaries and sets
6. String methods
7. File I/O
8. Error handling with try/except

**Intermediate** (Weeks 4-6):
9. Classes and OOP
10. List comprehensions
11. Lambda functions
12. Generators and iterators
13. Decorators
14. Context managers
15. Modules and packages

**Libraries for my goal**:
16. [GOAL-SPECIFIC: requests, pandas, flask, etc.]

For each concept: clear explanation + 2-3 examples + practice exercise with solution.
Python gotchas to avoid.
```
