## 🎯 Prompt

```
Teach me React from zero to proficient.

Prerequisites check:
- JavaScript: [BEGINNER / INTERMEDIATE / CONFIDENT]
- HTML/CSS: [BEGINNER / INTERMEDIATE / CONFIDENT]

If prerequisites aren't met, tell me what to learn first.

**Phase 1 — Thinking in React** (Week 1):
1. Components: reusable UI pieces
2. JSX: HTML in JavaScript
3. Props: passing data to components
4. State: data that changes over time (useState)
5. Build: a counter, a todo list

**Phase 2 — React Patterns** (Weeks 2-3):
6. Conditional rendering
7. Lists and keys
8. Forms and controlled inputs
9. useEffect: side effects and cleanup
10. Context: share state without prop drilling

**Phase 3 — Real App** (Weeks 4-5):
11. React Router: multiple pages
12. Data fetching: fetch + TanStack Query
13. Error boundaries
14. Deploy to Vercel

Common React mistakes and how to avoid them.
```
