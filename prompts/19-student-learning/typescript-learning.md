## 🎯 Prompt

```
Teach me TypeScript effectively.

JavaScript level: [BEGINNER / INTERMEDIATE / ADVANCED]
Goal: [ADD TYPES TO EXISTING JS / START NEW PROJECT / INTERVIEW PREP]

TypeScript concepts:

**Week 1 — Type Basics**:
1. Why TypeScript: catch errors at compile time
2. Primitive types: string, number, boolean
3. Arrays and tuples
4. Object types and interfaces
5. Union types: `string | number`
6. Type inference: TypeScript guesses types

**Week 2 — Functions and Classes**:
7. Function parameter and return types
8. Optional and default parameters
9. Generic functions: `<T>`
10. Classes with typed properties

**Week 3 — Advanced Types**:
11. Type aliases vs interfaces
12. Intersection types
13. Mapped types: `Partial<T>`, `Required<T>`, `Pick<T>`
14. Conditional types: `T extends X ? Y : Z`
15. Template literal types

**Week 4 — Real-World TypeScript**:
16. tsconfig.json: strict mode, paths
17. Typing API responses
18. Utility types mastery

For each: examples + common mistakes.
```
