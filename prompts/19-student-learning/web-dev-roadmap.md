## 🎯 Prompt

```
Create a web development learning roadmap for me.

My background: [COMPLETE BEGINNER / SOME PROGRAMMING / BACKEND ONLY / etc.]
Goal: [FULL-STACK DEVELOPER / FRONTEND SPECIALIST / GET A JOB IN 6 MONTHS]
Time available: [HOURS PER WEEK]

Personalized roadmap:

**Phase 1 — Web Fundamentals** (4 weeks):
1. HTML: structure and semantics
2. CSS: styling, flexbox, grid
3. JavaScript: programming basics in browser

**Phase 2 — Modern JavaScript** (4 weeks):
4. ES6+ features
5. DOM manipulation
6. Fetch API, promises, async/await

**Phase 3 — React** (6 weeks):
7. Components, props, state
8. Hooks: useState, useEffect, useContext
9. React Router, data fetching

**Phase 4 — Backend** (6 weeks):
10. Node.js + Express
11. PostgreSQL + ORMs
12. REST APIs
13. Authentication

**Phase 5 — Full Stack Project** (4 weeks):
14. Build and deploy a complete app

Resources for each phase (free first).
```

## 💡 Tips & Variations
